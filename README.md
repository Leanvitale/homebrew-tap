# Pruneo para Homebrew

[Pruneo](https://pruneo.app) limpia tu Mac sin borrar lo que importa: separa lo seguro, lo que conviene revisar y lo que no se toca nunca, y lo que limpia queda 48 horas en cuarentena.

```bash
brew install --cask leanvitale/tap/pruneo
```

También instala el comando `pruneo` para la terminal (`pruneo scan`, `pruneo clean`, `pruneo quarantine`).

- Actualizar: `brew upgrade --cask pruneo`
- Desinstalar: `brew uninstall --cask pruneo` (con `--zap` borra también ajustes, cuarentena y limpiezas programadas)

Este repositorio solo tiene la receta de instalación. Pruneo se descarga firmada y notarizada por Apple desde [pruneo.app](https://pruneo.app).
